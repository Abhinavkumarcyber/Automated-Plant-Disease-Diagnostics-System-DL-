# Automated Plant Disease Diagnostics System

A Deep Learning computer vision system utilizing PyTorch and Transfer Learning (ResNet-18) to classify plant leaf diseases accurately.

## Project Structure
- `data.csv`: Image dataset annotations, categories, and disease severity scores.
- `train.py`: PyTorch Deep Learning training code using CNN transfer learning.
- `requirement.txt`: Python dependencies including PyTorch and Torchvision.
